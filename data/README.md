# data/

Git-ignored except this file. Populated by `pitaco data` (M1) and published to the Hugging Face Hub.

- `raw/` — Olist CSVs as downloaded (CC BY-NC-SA 4.0)
- `interim/` — cleaned, PII-scrubbed, deduplicated reviews
- `processed/` — frozen splits (gold dev/test pools, silver pool)
- `annotations/` — hand labels (gold) and teacher labels (silver)
